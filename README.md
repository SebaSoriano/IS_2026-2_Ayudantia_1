# Generador de consejos random
Una web interactiva que consume una API pública para mostrar un consejo tras presionar un botón.

## Funcionalidades
Obtiene un consejo aleatorio en tiempo real.
Indicador de carga.
Bloqueo temporal del botón.
Evita el almacenameinto en cache.

## Tecnologías utilizadas
**HTML5**
**CSS3**
**Javascript**
**API pública**

## Cómo ejecutar la web
1. Clona el repositorio
```bash
git clone [https://github.com/SebaSoriano/IS_2026-2_Ayudantia1](https://github.com/SebaSoriano/IS_2026-2_Ayudantia1)
```

2. Anda a la carpeta
```bash
cd IS_2026-2_Ayudantia1
```

3. Abre el archivo index.html en tu browser
